# Nombits

A minimalist Java Swing ordering, cashier, and kitchen display system designed with role-based screen navigation and data-structure-driven workflows (such as Stack-based undo, FIFO Queue order flow, search, and price sorting).

## How to Run

### Prerequisites
- **Java Development Kit (JDK)** (JDK 11 or newer recommended)

### Option 1: Using VS Code
1. Open the project folder in VS Code (make sure the **Extension Pack for Java** is installed).
2. Open `src/NombitsFrame.java`.
3. Click **Run** above `public static void main(String[] args)`, **or** run via the integrated terminal:
   ```bash
   cd src
   javac NombitsFrame.java
   java NombitsFrame
